GPCR-G protein-arrestin, RTK-MAPK-PI3K, Wnt, Notch, Hippo, JAK-STAT, TGF-β — an interwoven network and the biased-agonism therapeutic paradigm.

Cell signaling can be grouped into 7 major axes — each independent yet interwoven:

💡
關鍵反思：20 世紀觀念是「一個訊號→一條通路→一個結果」，但今日網路生物學已揭示每個結果是多通路加權整合。EGF 在乳腺上皮促增殖、在肝促分化、在腫瘤促 EMT——同樣的受體，網路 context 決定結果。 Key reframe: 20th-century view: "one signal → one pathway → one outcome". Modern network biology: every outcome is a weighted integration of multiple pathways. EGF promotes proliferation in mammary epithelium, differentiation in liver, EMT in tumors — same receptor, network context determines outcome.
GPCR

一、GPCR 與 biased agonism

GPCR 為人類最大膜蛋白家族（~800 個），分為：

  • Class A (Rhodopsin-like)：~700 個；β2AR, μ-opioid, 5-HT 等
  • Class B (Secretin-like)：GLP1R (糖尿病、肥胖)、GCGR
  • Class C：mGluR、GABAB、CaSR（含 VFT large ECD）
  • Class F (Frizzled)：與 Wnt 連結；FZD1-10, SMO

G-protein cycle：

  1. 配體結合 → 7-TM 構象改變 → GαGDP → GαGTP（GDP/GTP exchange）
  2. GαGTP 與 Gβγ 分離，活化 effector：Gαs→AC↑→cAMP↑；Gαi→AC↓；Gαq→PLCβ→IP3+DAG；Gα12/13→RhoGEF
  3. RGS proteins 加速 GαGTP 水解 → 回到 GDP 狀態
  4. GRK 磷酸化 GPCR C-末端 → 招募 β-arrestin → 內吞與 desensitization

Biased agonism / functional selectivity：不同配體偏好穩定不同的 GPCR 構象，使 G-protein arm 與 β-arrestin arm 出現不對等活化。經典案例：TRV130 (oliceridine) 是 μ-opioid 的 G-protein-biased agonist，2020 年 FDA 核准——目標是保留鎮痛（Gi 介導）但減少 β-arrestin 介導的呼吸抑制與便秘。

GPCRs are the largest human membrane protein family (~800):

  • Class A (Rhodopsin-like): ~700; β2AR, μ-opioid, 5-HT etc.
  • Class B (Secretin-like): GLP1R (diabetes, obesity), GCGR
  • Class C: mGluR, GABAB, CaSR (large VFT ECD)
  • Class F (Frizzled): linked to Wnt; FZD1-10, SMO

G-protein cycle:

  1. Ligand binding → 7-TM rearrangement → GαGDP → GαGTP (exchange)
  2. GαGTP separates from Gβγ, activates effectors: Gαs→AC↑→cAMP↑; Gαi→AC↓; Gαq→PLCβ→IP3+DAG; Gα12/13→RhoGEF
  3. RGS proteins accelerate GαGTP hydrolysis → back to GDP
  4. GRK phosphorylates GPCR C-tail → recruits β-arrestin → internalization & desensitization

Biased agonism / functional selectivity: different ligands stabilize different GPCR conformations, producing unequal activation of G-protein vs β-arrestin arms. Classic case: TRV130 (oliceridine), a G-protein-biased μ-opioid agonist, FDA-approved 2020 — retains analgesia (Gi) but reduces β-arrestin-mediated respiratory depression and constipation.

⚠️
2024 質疑：oliceridine 的「bias」在臨床上的優勢仍有限——部分研究顯示其呼吸抑制與嗎啡相比並非顯著減少。biased agonism 的概念正確，但臨床轉譯比想像複雜（多項通路同時被調控、不同組織反應不同）。 2024 caveat: Clinical advantage of oliceridine's bias is debated — some studies show only modest reduction in respiratory depression vs morphine. The concept is sound, but clinical translation is harder than expected (multiple parallel pathways, tissue-dependent responses).
RTK

二、RTK 雙臂

RTK（如 EGFR、FGFR、IGFR、MET、PDGFR）為單次跨膜，配體誘導二聚 → trans-autophosphorylation 於細胞質尾端 Tyr 位點 → 招募 SH2/PTB-domain adaptor (Grb2, Shc, PLCγ, p85) → 啟動下游兩條主軸：

RTKs (EGFR, FGFR, IGFR, MET, PDGFR) are single-pass; ligand binding induces dimerization → trans-autophosphorylation of cytoplasmic Tyr → recruits SH2/PTB adaptors (Grb2, Shc, PLCγ, p85) → activates two main axes:

🌿

Ras-MAPK

Grb2-SOS → Ras-GTP → Raf → MEK → ERK1/2 → 核轉位 → ELK1, MYC, FOS。促增殖與分化決定。BRAF V600E 為 melanoma 主要驅動（vemurafenib, dabrafenib）。

Grb2-SOS → Ras-GTP → Raf → MEK → ERK1/2 → nuclear → ELK1, MYC, FOS. Proliferation/fate. BRAF V600E drives melanoma (vemurafenib, dabrafenib).

🧪

PI3K-AKT-mTOR

p85 + p110 → PIP2→PIP3 → AKT (PDK1 + mTORC2 雙磷酸化 T308/S473)。mTORC1 (Raptor)：S6K/4E-BP1 → 合成；mTORC2 (Rictor)：AKT/SGK → 生存。PIK3CA 突變在乳癌約 30-40%。

p85 + p110 → PIP2→PIP3 → AKT (PDK1 + mTORC2 phosphorylate T308/S473). mTORC1 (Raptor): S6K/4E-BP1 → biosynthesis; mTORC2 (Rictor): AKT/SGK → survival. PIK3CA mutated in 30-40% of breast cancer.

⛔

負調控

PTEN 去 PIP3；GAP (NF1) 加速 Ras-GTP→GDP；DUSP 去磷酸化 ERK。PTEN/NF1 為腫瘤抑制基因。

PTEN dephosphorylates PIP3; GAP (NF1) accelerates Ras-GTP→GDP; DUSP dephospho ERK. PTEN/NF1 are tumor suppressors.

發育訊號

三、發育與身分訊號

Wnt canonical (β-catenin)：

  • OFF：β-catenin 被「destruction complex (APC + Axin + GSK3β + CK1)」磷酸化 → β-TrCP 招募 → K48-Ub → proteasome 降解
  • ON：Wnt 結合 Frizzled + LRP5/6 → LRP6 PPPSP motif 磷酸化 (CK1, GSK3 paradoxical) → Axin 被招募到膜上 → destruction complex 解體 → β-catenin 積累、核轉位、與 TCF/LEF 結合啟動 c-MYC, CCND1, AXIN2 (負回饋)
  • APC 突變是 colorectal cancer 早期 hit（FAP 與 80% sporadic CRC）

Notch：相鄰細胞間訊號（「lateral inhibition」）：

  1. Delta/Jagged ligand 結合相鄰細胞 Notch 受體
  2. ADAM10/17 切 S2 site；γ-secretase (PS1/2, NCT, APH1, PEN2) 切 S3 site → 釋出 NICD
  3. NICD 進核 + CSL (RBPJ) + Mastermind → 轉錄 HES, HEY 等 bHLH 抑制因子
  4. T-ALL: NOTCH1 突變率 >50%；GSI (γ-secretase inhibitor) 臨床但腸道副作用顯著

Hippo 通路：MST1/2 + SAV1 → LATS1/2 + MOB1 → 磷酸化 YAP/TAZ → 14-3-3 細胞質扣留 / 降解。LATS 失活 → YAP/TAZ 進核 + TEAD → CTGF, CYR61 → 增殖。Hippo 整合細胞密度、機械應力、極性、能量訊號——是 Ch10 機械轉導的核心終點。

Wnt canonical (β-catenin):

  • OFF: β-catenin phosphorylated by the destruction complex (APC + Axin + GSK3β + CK1) → β-TrCP → K48-Ub → proteasome
  • ON: Wnt binds Frizzled + LRP5/6 → LRP6 PPPSP motif phosphorylation (CK1, GSK3 paradoxical) → Axin pulled to membrane → destruction complex dissolves → β-catenin accumulates, nucleus → TCF/LEF → c-MYC, CCND1, AXIN2 (neg feedback)
  • APC mutation is the early hit in CRC (FAP and 80% sporadic CRC)

Notch: neighbor-to-neighbor signaling ("lateral inhibition"):

  1. Delta/Jagged on neighboring cell binds Notch
  2. ADAM10/17 cleaves S2; γ-secretase (PS1/2, NCT, APH1, PEN2) cleaves S3 → releases NICD
  3. NICD enters nucleus + CSL (RBPJ) + Mastermind → HES/HEY bHLH repressors
  4. T-ALL: NOTCH1 mutated >50%; GSIs limited by gut side effects

Hippo: MST1/2 + SAV1 → LATS1/2 + MOB1 → phospho YAP/TAZ → 14-3-3 sequestration / degradation. LATS off → YAP/TAZ nuclear + TEAD → CTGF, CYR61 → proliferation. Hippo integrates cell density, mechanical stress, polarity, energy — the core endpoint of mechanotransduction (Ch10).

細胞激素

四、細胞激素與 TGF-β

JAK-STAT：細胞激素 (IFN, IL-2, IL-6, GM-CSF) 結合 → 受體二聚 → JAK1-3, TYK2 trans-phosphorylation → STAT1-6 被招募並磷酸化 → STAT 二聚（pSTAT-pSTAT 與 SH2-domain pTyr 互換）→ 核轉位 → GAS / ISRE 元件。JAK 抑制劑 (ruxolitinib, tofacitinib, baricitinib) 廣泛用於 MPN、RA、AA、COVID-19 ARDS、atopic dermatitis。

TGF-β/SMAD：

  1. TGF-β 結合 TβRII → 招募並磷酸化 TβRI（GS domain）
  2. TβRI 磷酸化 SMAD2/3 (C-tail SSXS)
  3. pSMAD2/3 + SMAD4 → 核轉位 → SBE
  4. 主要輸出：EMT（Snail, Slug, ZEB↑, E-cadherin↓）、纖維化（collagen, αSMA↑）、免疫抑制（Foxp3 Treg）
  5. I-SMAD (SMAD6/7) 為負回饋

TGF-β 在晚期癌症由抑制者變為促進者（雙面角色），是 immune-cold tumor 的關鍵 → anti-TGF-β + anti-PD-L1 bispecific (bintrafusp) 為治療嘗試。

JAK-STAT: cytokines (IFN, IL-2, IL-6, GM-CSF) → receptor dimerization → JAK1-3, TYK2 trans-phosphorylation → STAT1-6 recruited and phosphorylated → STAT dimers (pSTAT-pSTAT, SH2-pTyr swap) → nucleus → GAS / ISRE. JAK inhibitors (ruxolitinib, tofacitinib, baricitinib) widely used in MPN, RA, AA, COVID-19 ARDS, atopic dermatitis.

TGF-β/SMAD:

  1. TGF-β binds TβRII → recruits and phosphorylates TβRI (GS domain)
  2. TβRI phospho SMAD2/3 (C-tail SSXS)
  3. pSMAD2/3 + SMAD4 → nucleus → SBE
  4. Outputs: EMT (Snail, Slug, ZEB↑, E-cadherin↓), fibrosis (collagen, αSMA↑), Treg immune suppression
  5. I-SMADs (SMAD6/7) provide negative feedback

TGF-β switches from tumor suppressor (early) to promoter (late) — driving immune-cold tumors. Anti-TGF-β + anti-PD-L1 bispecific (bintrafusp) is being trialed.
