核酸高階結構

不只是雙螺旋——G-quadruplex、R-loop、RNA 三級結構與核酸開關如何在基因調控中扮演關鍵角色。

Beyond the double helix — G-quadruplexes, R-loops, RNA tertiary structure, and riboswitches as key regulators of gene expression.

概覽

DNA / RNA 的多型性

標準教科書呈現的 B-DNA 雙螺旋只是核酸構象的一個成員。基因組中還充滿了 A-DNA、Z-DNA、G-quadruplex (G4)、i-motif、R-loop、cruciform 與三鏈結構。這些「非 B」結構在 DNA 複製、轉錄、染色質開合、端粒維持與染色體穩定性中具有關鍵調控功能。

RNA 則因單股的特性，能折疊成複雜的三級結構：tRNA cloverleaf、ribozyme、riboswitch、長非編碼 RNA scaffolds。SHAPE-MaP、icSHAPE、PARS 等高通量 RNA 結構探測技術已能在全基因組尺度繪製 RNA 結構地圖。

The textbook B-DNA double helix is just one of many nucleic acid conformations. Genomes contain A-DNA, Z-DNA, G-quadruplexes (G4), i-motifs, R-loops, cruciform, and triplex structures — each with regulatory roles in replication, transcription, chromatin, telomeres, and chromosome stability.

RNA, being single-stranded, folds into complex tertiary structures: tRNA cloverleaf, ribozymes, riboswitches, lncRNA scaffolds. High-throughput probing (SHAPE-MaP, icSHAPE, PARS) now maps RNA structure transcriptome-wide.

💡
核心原則：核酸不是被動的訊息載體——序列同時編碼了結構與調控。同一段 DNA 在不同 superhelical 或轉錄狀態下，可形成不同的二級結構。 Core principle: Nucleic acids are not passive carriers — sequence encodes structure and regulation. The same DNA can adopt different secondary structures depending on supercoiling and transcription state.
非 B 結構

一、G-quadruplex、R-loop 與 Z-DNA

⚛️

G-quadruplex (G4)

四股 G:G:G:G 平面堆疊。富集於啟動子（c-MYC、KRAS）、5′ UTR、端粒。穩定化可抑制轉錄；G4 結合配體（CX-5461 等）為癌症療法新方向。BG4 抗體可全基因組標定 G4 位置。

Four-stranded G:G:G:G planar stacking. Enriched at promoters (c-MYC, KRAS), 5′ UTRs, telomeres. Stabilization represses transcription; G4 ligands (CX-5461) are emerging cancer therapeutics. BG4 antibody maps G4s genome-wide.

🪢

R-loop

RNA-DNA 雜合 + 置換出的單股 DNA。佔 5-8% 基因組，CpG 島富集。生理功能：免疫重組、轉錄終止、CRISPR-Cas9 切割。病理：複製-轉錄衝突、基因體不穩定（ALS/FTD、AGS）。

RNA-DNA hybrid + displaced ssDNA. 5–8% of genome, enriched at CpG islands. Physiological: immunoglobulin class switching, transcription termination, CRISPR cleavage. Pathological: replication-transcription conflicts (ALS/FTD, AGS).

↩️

Z-DNA

左旋雙螺旋；GC 重複序列 + 負 supercoiling 誘導。ADAR1 與 ZBP1 是 Z-DNA/Z-RNA 感應器，連結至 innate immunity 與 necroptosis（Ch17）。

Left-handed helix; induced by GC repeats + negative supercoiling. ADAR1 and ZBP1 are Z-DNA/Z-RNA sensors linking to innate immunity and necroptosis (Ch17).

RNA 結構

二、RNA 二級/三級結構與 Riboswitch

RNA 折疊遵循「結構決定功能」的核心原則：

  • 二級結構元件：hairpin、bulge、internal loop、multi-branch loop、pseudoknot
  • 三級交互：kissing loops、coaxial stacking、A-minor motif、tetraloop-tetraloop receptor
  • Riboswitch：5′ UTR 上的代謝物感應器（如 TPP、purine、SAM riboswitch），不依賴蛋白即可調控轉錄終止或轉譯起始
  • 催化 RNA (ribozyme)：自剪接 group I/II introns、ribosomal peptidyl transferase、CRISPR Cas9 sgRNA scaffold

RNA folding follows "structure determines function":

  • 2° elements: hairpin, bulge, internal loop, multi-branch loop, pseudoknot
  • 3° interactions: kissing loops, coaxial stacking, A-minor motif, tetraloop-receptor
  • Riboswitch: 5′ UTR metabolite sensors (TPP, purine, SAM) regulating transcription termination or translation initiation without protein
  • Ribozyme: self-splicing group I/II introns, ribosomal peptidyl transferase, CRISPR Cas9 sgRNA scaffold
⚠️
SARS-CoV-2 frameshift pseudoknot：位於 ORF1a/b 重疊區，誘導 -1 ribosomal frameshift 以表達 RdRp。已成為 paxlovid 之外的潛在抗病毒標的。 SARS-CoV-2 frameshift pseudoknot: in the ORF1a/b overlap, drives -1 ribosomal frameshift to express RdRp. A potential antiviral target beyond paxlovid.

三、結構預測與探測流程

# G-quadruplex 預測 + RNA 二級結構視覺化
library(pqsfinder)
library(Biostrings)
seq <- readDNAStringSet("promoter.fa")
pqs <- pqsfinder(seq[[1]], min_score=40)
# 取出 G4 位置與分數
head(as.data.frame(pqs))
# RNA 二級結構視覺化
library(R4RNA)
helix <- readHelix("rna.helix")
plotHelix(helix, line=TRUE, arrow=TRUE)
# 使用 ViennaRNA Python API (RNAfold)
import RNA
seq = "GGGAAUCCGGGAAACCCGGAAUUCC"
fc  = RNA.fold_compound(seq)
(ss, mfe) = fc.mfe()
print(f"MFE structure: {ss}")
print(f"MFE energy:    {mfe:.2f} kcal/mol")

# Partition function + base-pair probabilities
fc.pf()
bpp = fc.bpp()
# bpp[i][j] = P(i pairs with j)

# 對 SHAPE 數據進行約束折疊
fc.sc_add_SHAPE_deigan(shape_react, m=1.8, b=-0.6)
(ss2, mfe2) = fc.mfe()
# ShapeMapper2 — SHAPE-MaP 數據處理
shapemapper \
  --target rna_target.fa \
  --name MY_RNA \
  --modified --R1 mod_R1.fq.gz --R2 mod_R2.fq.gz \
  --untreated --R1 un_R1.fq.gz --R2 un_R2.fq.gz \
  --denatured --R1 dn_R1.fq.gz --R2 dn_R2.fq.gz \
  --out shapemap_out --overwrite

# 用 SHAPE 反應度引導 RNAfold
RNAfold --shape=shapemap_out/MY_RNA_profile.txt \
        --shapeMethod=D -p < rna_target.fa
