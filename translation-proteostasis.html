轉譯調控與蛋白穩態

從 eIF4F cap 識別、uORF 重編碼，到 ISR/UPR、ubiquitin code 與 ribosome quality control——蛋白穩態網絡的當代藍圖。

From eIF4F cap recognition and uORF reprogramming to ISR/UPR, the ubiquitin code, and ribosome quality control — a modern map of the proteostasis network.

概覽

蛋白穩態網絡

細胞每秒合成 ~10⁵-10⁶ 個蛋白；同時面對誤折疊、損傷、聚集的持續壓力。蛋白穩態 (proteostasis) 由三大模組維持，每個都偶合於環境訊號：

  1. 合成 (synthesis)：cap-dependent 翻譯、scanning、uORF、密碼子優化
  2. 折疊 (folding)：HSP70/HSP90/HSP60/CCT chaperone 網絡
  3. 降解 (degradation)：UPS (ubiquitin-proteasome) + autophagy (Ch18)

當這些模組失衡——稱為「proteostasis collapse」——出現於 Alzheimer (Aβ, tau)、Parkinson (α-synuclein)、Huntington (polyQ)、ALS (TDP-43)，並普遍見於衰老 (Ch19)。

Cells synthesize ~10⁵-10⁶ proteins per second while facing constant misfolding, damage, and aggregation. Proteostasis is maintained by three modules, each coupled to environmental signals:

  1. Synthesis: cap-dependent translation, scanning, uORFs, codon optimality
  2. Folding: HSP70/HSP90/HSP60/CCT chaperone networks
  3. Degradation: UPS (ubiquitin-proteasome) + autophagy (Ch18)

Imbalance — "proteostasis collapse" — drives Alzheimer's (Aβ, tau), Parkinson's (α-synuclein), Huntington's (polyQ), ALS (TDP-43), and is general in aging (Ch19).

💡
分子箴言：「蛋白的命運從第一個密碼子開始決定」——signal peptide 決定 ER 靶向、N-端規則決定半衰期、密碼子優化決定 ribosome 速度，皆在合成階段已寫入。 Aphorism: "A protein's fate is sealed at the first codon" — signal peptide directs ER targeting, N-end rule sets half-life, codon optimality sets ribosome speed — all encoded at synthesis.
起始

一、起始與 uORF

真核轉譯起始為「掃描模型 (scanning model)」：

  1. eIF4F (eIF4E + eIF4G + eIF4A) 結合 m7G cap；eIF4A 解開 5′ UTR 二級結構
  2. 43S PIC (40S + eIF1/1A/2-GTP-Met-tRNAi/3/5) 被 eIF4G 招募
  3. 40S 掃描至 AUG（Kozak: gccRccAUGG，R=嘌呤）
  4. eIF5 觸發 eIF2-GTP 水解 → eIF2-GDP 釋出、60S 加入 → 80S
  5. 第一肽鍵形成

uORF (upstream ORF) 是 5′ UTR 中位於主 ORF 上游的小 ORF，常作為「過濾器」抑制下游表達。ATF4、GCN4 的奇妙設計：在正常狀態 uORF1 被翻譯後 ribosome 重啟動，使用 uORF2 而跳過主 ORF；在應激下 eIF2-GTP 稀缺，重啟動慢，ribosome 直接抵達主 ORF 啟動。這實現「應激誘導的翻譯啟動」。

Eukaryotic initiation follows the scanning model:

  1. eIF4F (eIF4E + eIF4G + eIF4A) binds m7G cap; eIF4A unwinds 5′ UTR
  2. 43S PIC (40S + eIF1/1A/2-GTP-Met-tRNAi/3/5) recruited by eIF4G
  3. 40S scans to AUG (Kozak: gccRccAUGG, R=purine)
  4. eIF5 triggers eIF2-GTP hydrolysis → eIF2-GDP released, 60S joins → 80S
  5. First peptide bond

uORFs (upstream ORFs) in 5′ UTRs filter downstream translation. The elegant ATF4 / GCN4 design: under normal conditions, after uORF1 translation, the ribosome reinitiates at uORF2, skipping the main ORF; under stress, eIF2-GTP is scarce, reinitiation is slow, the ribosome reaches the main ORF directly. This achieves stress-induced translation initiation.

應激網絡

二、ISR 與 UPR

ISR (Integrated Stress Response) 集中於 eIF2α 磷酸化（Ser51）。四個 kinase 偵測不同應激，殊途同歸：

ISR (Integrated Stress Response) converges on eIF2α phosphorylation (Ser51). Four kinases sense different stresses, all funneling to the same hub:

Kinase應激位置
GCN2胺基酸缺乏細胞質
PERKER 壓力ER 膜
HRIHeme / mito stress細胞質
PKRdsRNA細胞質

eIF2αP 結果：

  • 整體 cap-dependent 翻譯 下降 (~80%)
  • 含 uORF 的 ATF4 mRNA 反而上升翻譯 → 啟動 CHOP, GADD34, 胺基酸合成基因
  • 形成應力顆粒 (Ch4)：G3BP1 主導 LLPS
  • 持續活化 → CHOP 介導 apoptosis (Ch17)

UPR (Unfolded Protein Response)：ER 中 misfolded 蛋白超載，三條平行通路活化：

  • IRE1α：自磷酸化 + 切割 XBP1 mRNA → XBP1s 轉錄因子 → ER 擴張、chaperone 上調
  • PERK：磷酸化 eIF2α (ISR 分支) + ATF4 + Nrf2
  • ATF6：轉位至 Golgi → S1P/S2P 切割 → ATF6f TF

Consequences of eIF2αP:

  • Global cap-dependent translation drops (~80%)
  • uORF-containing ATF4 mRNA is preferentially translated → induces CHOP, GADD34, amino acid biosynthesis
  • Stress granules form (Ch4): G3BP1-driven LLPS
  • Sustained activation → CHOP → apoptosis (Ch17)

UPR (Unfolded Protein Response): ER misfolded-protein overload activates three parallel branches:

  • IRE1α: autophosphorylation + XBP1 mRNA splicing → XBP1s TF → ER expansion, chaperone upregulation
  • PERK: phosphorylates eIF2α (ISR arm) + ATF4 + Nrf2
  • ATF6: translocates to Golgi → S1P/S2P cleavage → ATF6f TF
⚠️
ISRIB：Walter lab 2013 發現小分子 ISRIB 可逆轉 eIF2αP 的下游效應（穩定 eIF2B GEF）。在小鼠模型改善 cognition、TBI 復原、prion disease。 ISRIB: Walter lab 2013 discovered a small molecule that reverses downstream eIF2αP effects (stabilizes eIF2B GEF). In mice it improves cognition, TBI recovery, and prion disease.

泛素級聯：E1 (UBA1) 活化 ubiquitin → E2 (~40 種) → E3 ligase (~600+ 種，分 RING/HECT/RBR) 賦予專一性。26S proteasome 為 K48-Ub 標記蛋白的主要降解機器：

  • 19S RP (regulatory particle)：辨識 Ub 鏈 (Rpn10/13)、解除泛素化 (Rpn11)、ATP 依賴解折疊 (Rpt1-6)、餵入 20S
  • 20S CP (core particle)：α₇β₇β₇α₇ 圓桶，β1/β2/β5 三個催化亞基 (caspase/trypsin/chymotrypsin-like)

藥物標靶：bortezomib、carfilzomib 是 β5 抑制劑，用於 multiple myeloma；MM 細胞依賴 plasma 細胞高蛋白合成 → 對蛋白酶體抑制特別敏感。

Ubiquitin cascade: E1 (UBA1) activates Ub → E2 (~40) → E3 ligase (~600+, RING/HECT/RBR) provides specificity. The 26S proteasome degrades K48-Ub-tagged proteins:

  • 19S RP: recognizes Ub chains (Rpn10/13), deubiquitinates (Rpn11), ATP-dependent unfolding (Rpt1-6), feeds 20S
  • 20S CP: α₇β₇β₇α₇ barrel; β1/β2/β5 catalytic subunits (caspase/trypsin/chymotrypsin-like)

Drugs: bortezomib, carfilzomib inhibit β5, used in multiple myeloma; MM cells depend on plasma-cell high protein output → exquisitely sensitive.

核糖體品管

四、核糖體品管

當 ribosome 在 mRNA 上「碰撞 (collision)」——前方 ribosome 停頓導致後方追撞——形成disome / trisome，這是異常訊號。應對機制：

  1. ZNF598 (E3) 識別 disome 介面，泛素化 RPS10/RPS20（K48 + K63 混合）
  2. ASCC 複合體 + Hbs1l-Pelota 將兩個 ribosome 分開
  3. NEMF 與 Listerin (LTN1) 於 60S 上抓住未完成肽鏈，添加 CAT-tail (Ala-Thr) 並用 K48-Ub 標記降解
  4. mRNA 透過 no-go decay (Dom34-Hbs1) 降解
  5. GCN2 sensor 偵測 disome → 觸發 ISR

RQC 失靈見於神經退化 (NEMF 突變 → 兒童神經病變)。

When ribosomes collide (a stalled leader hit from behind), they form disomes/trisomes — an aberrant signal. Response:

  1. ZNF598 (E3) recognizes the disome interface, ubiquitinates RPS10/RPS20 (K48 + K63)
  2. ASCC + Hbs1l-Pelota split the disome
  3. NEMF + Listerin (LTN1) grab nascent chains on 60S, add CAT-tail (Ala-Thr), K48-Ub tag for degradation
  4. mRNA degraded via no-go decay (Dom34-Hbs1)
  5. GCN2 senses disomes → triggers ISR

RQC failure causes neurodegeneration (NEMF mutations → pediatric neuropathy).
