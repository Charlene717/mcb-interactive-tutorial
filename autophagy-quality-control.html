自噬與細胞品質管控

從 ULK1 到 ATG9 lipid scramblase——選擇性自噬如何標靶清除受損胞器與聚集物。

From ULK1 to ATG9 lipid scramblase — selective autophagy targets damaged organelles and aggregates.

概覽

自噬：細胞的再生計畫

Autophagy（2016 Yoshinori Ohsumi 諾貝爾獎）並非單一「飢餓反應」，而是一系列以 ATG 蛋白為核心的降解品質管控網絡：

  • Macroautophagy：phagophore → autophagosome → fuse with lysosome
  • Microautophagy：lysosome 直接內陷吞噬
  • Chaperone-Mediated Autophagy (CMA)：LAMP2A + HSC70 + KFERQ motif，單分子層級
  • Selective autophagy：mitophagy、aggrephagy、ER-phagy、ribophagy、lysophagy、xenophagy 等

Autophagy (Yoshinori Ohsumi 2016 Nobel) is not a single starvation response but an ATG-driven degradation quality-control network:

  • Macroautophagy: phagophore → autophagosome → fusion with lysosome
  • Microautophagy: direct lysosomal invagination
  • CMA: LAMP2A + HSC70 + KFERQ motif, single-substrate level
  • Selective autophagy: mitophagy, aggrephagy, ER-phagy, ribophagy, lysophagy, xenophagy
💡
2024 ATG9：長久以來 ATG9 被視為「ATG 招募囊泡」，2020-2023 發現其為跨層脂質 scramblase，催化磷脂跨層雙向交換，是 phagophore 從 ER 接收脂質的關鍵——配合 ATG2 bridge LTP 完成大量供脂。 2024 ATG9: long viewed as a vesicle for ATG recruitment, 2020-2023 work shows it is a lipid scramblase catalyzing transbilayer flip-flop — key for phagophore receiving lipids from ER (paired with ATG2 bridge LTP for bulk supply).

選擇性自噬

二、選擇性自噬 receptor 圖譜

⚡

Mitophagy

PINK1-Parkin 軸：膜電位喪失 → PINK1 在 OMM 累積 → 磷酸化 Ub (S65) → 招募並活化 Parkin (E3 ligase) → 大量 Ub 鏈於 OMM 蛋白 → 招募 OPTN / NDP52（受 TBK1 磷酸化增強）→ LC3。Receptor-mediated mitophagy：BNIP3 / NIX / FUNDC1 直接含 LIR motif（缺氧誘導）。

PINK1-Parkin axis: depolarization → PINK1 accumulates on OMM → phosphorylates Ub (S65) → recruits/activates Parkin (E3 ligase) → polyUb chains on OMM proteins → recruits OPTN/NDP52 (TBK1-phosphorylated) → LC3. Receptor-mediated: BNIP3/NIX/FUNDC1 with LIR motifs (hypoxia-induced).

🗑️

Aggrephagy

蛋白聚集物（α-synuclein、Htt-polyQ、TDP-43）→ Ub 標記 → p62/SQSTM1、NBR1、TOLLIP 識別 → UBA domain 結合 Ub + LIR motif 結合 LC3。p62 自身可 LLPS 形成 condensate。

Aggregates (α-synuclein, Htt-polyQ, TDP-43) → Ub-tagged → p62/SQSTM1, NBR1, TOLLIP recognize via UBA domain (binds Ub) + LIR motif (binds LC3). p62 itself can LLPS into condensates.

📜

ER-phagy

區域特異受體：FAM134B（sheet ER、cuts via reticulon-homology domain）、RTN3L（tubule ER）、CCPG1、SEC62（recovery from UPR）、ATL3、TEX264（廣譜，大部分 ER-phagy 貢獻者）。皆含 LIR。

Region-specific receptors: FAM134B (sheet ER, scissions via reticulon-homology domain), RTN3L (tubule ER), CCPG1, SEC62 (UPR recovery), ATL3, TEX264 (broad, major contributor). All harbor LIR motifs.

🛡️

Xenophagy

胞內病原（Salmonella、Mtb）→ galectin-8 偵測露出糖鏈 → 招募 NDP52 → 結合 LC3。Mtb 在 macrophage 內藉抑制 phagosome-lysosome 融合逃避。

Cytosolic pathogens (Salmonella, Mtb) → galectin-8 detects exposed glycans → recruits NDP52 → LC3. Mtb evades by blocking phagosome-lysosome fusion in macrophages.

🧬

Nucleophagy / Lysophagy

核膜片段降解（核纖層蛋白損傷時）→ LC3 直接於核外膜結合 LMNB1。Lysophagy：LMP → galectin-3/8 → ESCRT 修補 + p62/NDP52/TAX1BP1。

Nuclear fragment degradation (lamina damage) → LC3 directly binds LMNB1 at outer nuclear membrane. Lysophagy: LMP → galectin-3/8 → ESCRT repair + p62/NDP52/TAX1BP1.

🔁

CMA

Chaperone-mediated：含 KFERQ-like motif（~30% 蛋白組）→ HSC70 結合 → 結合 LAMP2A 多聚化通道 → 解折疊穿入 lysosome → cathepsin 降解。單分子層級，無需囊泡。

Substrates with KFERQ-like motif (~30% proteome) → HSC70 binds → docks to multimerized LAMP2A channel → unfolded translocation → lysosomal cathepsins degrade. Single-substrate; no vesicle.

⚠️
CASM (Conjugation of ATG8 to Single Membrane)：新發現一條非典型 LC3 偶聯路徑——LC3 被偶聯至單膜結構（lysosome、endosome、phagosome）而非雙膜 phagophore。觸發者包含 ionophores、lysosomotropic drugs、TLR signaling。功能差異與經典 macroautophagy 不同。 CASM (Conjugation of ATG8 to Single Membrane): a newly defined non-canonical LC3 conjugation pathway — LC3 attaches to single membranes (lysosome, endosome, phagosome) rather than double-membrane phagophores. Triggers: ionophores, lysosomotropic drugs, TLR signaling. Functionally distinct from canonical macroautophagy.

# R: ImageJ 量化 LC3 puncta 配合 flux 計算
library(EBImage)
img <- readImage("GFP_LC3.tif")
g    <- gblur(img, sigma=1) - gblur(img, sigma=5)   # DoG
mask <- g > 0.02
puncta <- bwlabel(mask)
puncta_per_cell <- table(puncta)[-1]
# Flux = (LC3-II/actin)_BafA1 − (LC3-II/actin)_vehicle
df <- read.csv("WB_quant.csv")
flux <- df$LC3II[df$cond=="BafA1"] - df$LC3II[df$cond=="DMSO"]
cat("Autophagic flux index:", round(flux,2), "\n")
# Python: tandem mRFP-GFP-LC3 自動化分析
import tifffile, numpy as np
from skimage.feature import blob_log
g = tifffile.imread("GFP.tif"); r = tifffile.imread("mRFP.tif")
blobs_g = blob_log(g, min_sigma=1, max_sigma=3, threshold=0.02)
blobs_r = blob_log(r, min_sigma=1, max_sigma=3, threshold=0.02)
# Yellow puncta = autophagosome (GFP+ RFP+)
# Red-only puncta = autolysosome (GFP quenched)
yellow = len([b for b in blobs_g if np.any(np.linalg.norm(blobs_r[:,:2]-b[:2],axis=1)<2)])
red_only = len(blobs_r) - yellow
print(f"AP:{yellow}  AL:{red_only}  flux ratio={red_only/(yellow+1):.2f}")

自我檢核（3 題）

1. WB 測得實驗組 LC3-II 高於對照，但加入 bafilomycin A1 後兩組 LC3-II 一樣高，最合理結論是？

1. WB shows treatment increases LC3-II vs control, but with bafilomycin A1 both reach the same level. The best interpretation is:

A. 處理組自噬流量增加A. Treatment increases autophagic flux
B. 處理組自噬流量降低B. Treatment decreases flux
C. 處理組阻斷 autolysosome 降解，LC3-II 堆積——並非促進自噬C. Treatment blocks autolysosomal degradation, LC3-II accumulates — not enhanced autophagy
D. LC3-I 大量被切為 LC3-IID. LC3-I massively converted to LC3-II
✔ C：BafA1 dock 後若兩組同高，代表處理組是「fusion/degradation 被阻」，而非新生增多——即flux 並未增加。
✔ C: If BafA1 equalizes both groups, the treated group blocks fusion/degradation rather than enhancing biogenesis — flux did not actually rise.

2. PINK1-KO 細胞為何 mitophagy 缺陷？

2. Why are PINK1-KO cells mitophagy-deficient?

A. 無法生成 LC3-IIA. Cannot generate LC3-II
B. 無法在受損粒線體上磷酸化 Ub (S65)，無法招募/活化 ParkinB. Cannot phosphorylate Ub (S65) on damaged mito to recruit/activate Parkin
C. ATG7 表達下降C. ATG7 expression drops
D. mTORC1 永久活化D. mTORC1 constitutively active
✔ B：PINK1 是受損 OMM 上的 phospho-ubiquitin 製造者；無 PINK1 即無 pS65-Ub 平台，Parkin 無法活化。
✔ B: PINK1 generates pS65-Ub on damaged OMM; without it Parkin cannot be recruited or activated.

3. (T/F) ATG9 is not just a vesicle for ATG recruitment — post-2020 studies established it as a transbilayer lipid scramblase, key for phagophore lipid acquisition.
