細胞週期與檢查點

CDK-cyclin 振盪器、Rb-E2F 開關、SAC 警報——細胞如何確保「一次只複製一次、分裂無錯」？

CDK-cyclin oscillator, Rb-E2F switch, SAC alarms — how cells ensure "once and only once" replication and error-free division.

概覽

振盪器 + 切換 + 檢查

細胞週期的核心是 CDK (Cyclin-Dependent Kinase) 與 Cyclin 形成的振盪器。CDK 蛋白量穩定，但 cyclin 在每個階段由轉錄合成、由 APC/C 泛素降解，使 CDK 活性呈週期性振盪。不同時期的 CDK-cyclin 組合磷酸化不同基質，推動 G1→S→G2→M。

三大不可逆切換 (bistable switches)： ① Restriction point (R)—Rb 過磷酸化釋放 E2F → S phase commitment；② G2/M trigger—CDK1-cyclin B 自我活化迴路 (Wee1↓ + CDC25↑)；③ Metaphase-Anaphase—APC/C 突然降解 securin/cyclin B → cohesin 切斷。

檢查點 (checkpoints)：① DNA damage (ATM/ATR-CHK)；② Replication stress (ATR-CHK1)；③ Spindle Assembly Checkpoint (SAC)。

The core is an oscillator built from CDK and Cyclin. CDK levels are stable, but cyclins are synthesized each phase and ubiquitinated by APC/C, giving CDK activity a periodic oscillation. Different CDK-cyclin combinations phosphorylate distinct substrates, driving G1→S→G2→M.

Three irreversible bistable switches: (1) Restriction point (R) — hyper-phosphorylated Rb releases E2F → S-phase commitment; (2) G2/M trigger — CDK1-cyclin B autoactivation loop (Wee1 down + CDC25 up); (3) Metaphase-Anaphase — APC/C abruptly degrades securin/cyclin B → cohesin cleavage.

Checkpoints: (1) DNA damage (ATM/ATR-CHK); (2) replication stress (ATR-CHK1); (3) Spindle Assembly Checkpoint (SAC).

Rb-E2F「sigmoidal」開關 (Yao 2008)：低細胞分裂訊號時 Rb 緊抓 E2F，S phase 基因沉默。Mitogen → cyclin D-CDK4/6 「monoP-Rb」（解除部分抑制）→ cyclin E-CDK2「hyperP-Rb」→ E2F 釋放 → 轉錄 cyclin E、CDC6、Cdt1、CDK2——形成正回饋環，使開關呈雙穩態（無中間狀態）。

2024 修正：Sage 與 Spencer 實驗室發現 Rb 並非「全有/全無」，而是多位點漸進磷酸化 (multi-site progressive)——12+ 磷酸化位點不同組合對應不同細胞行為，這解釋了某些癌細胞在 Rb 部分磷酸化下持續循環。

Sigmoidal Rb-E2F switch (Yao 2008): low mitogen → Rb grips E2F; S-phase genes silent. Mitogen → cyclin D-CDK4/6 mono-P Rb (partial release) → cyclin E-CDK2 hyper-P Rb → E2F released → transcribes cyclin E, CDC6, Cdt1, CDK2 — a positive feedback loop yielding bistability (no intermediate state).

2024 update: Sage and Spencer labs show Rb is not "all-or-none" but multi-site progressive phosphorylation — different combinations of 12+ sites map to distinct behaviors, explaining how some cancer cells cycle with partial Rb phosphorylation.

⚠️
臨床突破：CDK4/6 抑制劑 palbociclib, ribociclib, abemaciclib 用於 ER+/HER2− 乳癌——透過抑制 Rb 磷酸化使腫瘤細胞 G1 阻滯。代表性 PALOMA-3 試驗顯示 mPFS 由 4.6 → 9.2 個月。Resistance 機制：Rb 缺失、cyclin E 擴增、CDK6 過表達。 Clinical breakthrough: CDK4/6 inhibitors palbociclib, ribociclib, abemaciclib for ER+/HER2− breast cancer — block Rb phosphorylation, G1 arrest. PALOMA-3: mPFS 4.6 → 9.2 months. Resistance: Rb loss, cyclin E amplification, CDK6 overexpression.
DNA 損傷

二、DNA 檢查點

ATM 路徑 (DSB)：DNA 雙股斷裂 (DSB) 被 MRN 複合體 (MRE11-RAD50-NBN) 感應 → 招募並活化 ATM 激酶 → 磷酸化 H2AX-S139 (γH2AX) 與下游 CHK2-T68。CHK2 磷酸化 CDC25A 引發其降解，同時穩定 p53 (S15-P)，p53 誘導 p21 → 抑制 CDK2 → G1 停滯或 G2 停滯。

ATR 路徑 (ssDNA / 複製壓力)：單股 DNA 被 RPA 包覆，招募 ATRIP-ATR，與 9-1-1 (RAD9-HUS1-RAD1)、TOPBP1/ETAA1 形成活化平台。ATR 磷酸化 CHK1-S345，CHK1 磷酸化 CDC25 (S76)、Wee1，並抑制 origin firing——這是複製叉穩定的關鍵。

2024 進展：ATR 抑制劑 (ceralasertib, elimusertib) 在 BRCA-deficient 或 ATM-loss 腫瘤中合成致死；CHK1 inhibitors (prexasertib) 於 PARP 抑制劑抗性腫瘤再敏感化。

ATM pathway (DSB): double-strand breaks sensed by MRN (MRE11-RAD50-NBN) → recruit and activate ATM → phosphorylates H2AX-S139 (γH2AX) and downstream CHK2-T68. CHK2 phosphorylates CDC25A for degradation, stabilizes p53 (S15-P), p53 induces p21 → inhibits CDK2 → G1 or G2 arrest.

ATR pathway (ssDNA / replication stress): ssDNA coated by RPA recruits ATRIP-ATR; with 9-1-1 (RAD9-HUS1-RAD1) and TOPBP1/ETAA1 forms an activation platform. ATR phosphorylates CHK1-S345; CHK1 phosphorylates CDC25 (S76), Wee1, and suppresses origin firing — key for replication fork stabilization.

2024 progress: ATR inhibitors (ceralasertib, elimusertib) are synthetically lethal in BRCA-deficient or ATM-loss tumors; CHK1 inhibitors (prexasertib) re-sensitize PARP-inhibitor-resistant tumors.

紡錘體檢查點

三、紡錘體組裝檢查點

SAC 確保每對姊妹染色體都已雙極性 (amphitelic) 附著才允許 APC/C-CDC20 活化、cohesin 切斷、anaphase 開始。任何未連接 (unattached) 或單極連接 (monotelic)、同極連接 (syntelic)、合併連接 (merotelic) 的 kinetochore 都會發出「等！」訊號。

核心機制：未附著 kinetochore 招募 Mad1-Mad2 模板，催化遊離 Mad2 從 open conformation 轉為 closed C-Mad2 ↔ CDC20 → 與 BubR1-Bub3 形成 MCC (Mitotic Checkpoint Complex)，MCC 鎖住 APC/C-CDC20。

附著錯誤校正 (error correction)：當 kinetochore 連接錯誤時張力不足，Aurora B 激酶 (CPC: Aurora B-INCENP-Survivin-Borealin) 磷酸化 Ndc80 介面減弱微管附著，給予新嘗試機會。Haspin 磷酸化 H3-T3 招募 Survivin 至 centromere，這是 CPC 定位的關鍵。2024: Aurora B 抑制劑 (BAY-1816032) 在臨床試驗中觀察到 mitotic catastrophe 驅動的細胞死亡。

SAC ensures every sister kinetochore is amphitelically attached before APC/C-CDC20 activation, cohesin cleavage, and anaphase. Any unattached, monotelic, syntelic, or merotelic kinetochore raises a "wait!" signal.

Core mechanism: unattached kinetochores recruit Mad1-Mad2 templates that catalyze open→closed Mad2 + CDC20, joining BubR1-Bub3 to form MCC (Mitotic Checkpoint Complex), which locks APC/C-CDC20.

Error correction: wrong attachments lack tension; Aurora B kinase (CPC: Aurora B-INCENP-Survivin-Borealin) phosphorylates Ndc80 to weaken MT binding, allowing retry. Haspin phosphorylates H3-T3 to recruit Survivin to centromeres — key for CPC localization. 2024: Aurora B inhibitors (BAY-1816032) show mitotic-catastrophe-driven cell death in trials.

⏸️

MCC

Mad2-BubR1-Bub3-CDC20。隔離 CDC20，使 APC/C 無法多泛素化 securin/cyclin B。

Mad2-BubR1-Bub3-CDC20. Sequesters CDC20, prevents APC/C polyubiquitination of securin/cyclin B.

🧲

Aurora B (CPC)

感應「張力」——錯誤連接無張力 → 鄰近 Ndc80 → 磷酸化解除附著。

Tension sensor — wrong attachments lack tension → Ndc80 nearby → phosphorylation detaches.

✂️

Separase

SAC 滿足 → APC/C 降解 securin → separase 活化 → 切斷 cohesin SCC1/Rad21 → anaphase。

SAC satisfied → APC/C degrades securin → separase active → cleaves cohesin Rad21 → anaphase.

    elif g>thr and r<thr: return "S/G2/M"

# 比例: G1 ~ 60-70%; S ~ 10-20%; G2/M ~ 10-15% (asynchronous HeLa)
# Goldbeter 1991 minimal cell cycle oscillator (Python)
from scipy.integrate import odeint
import numpy as np

def cycle(y, t, vi=0.025, vd=0.25, kd=0.01):
    C, M, X = y  # cyclin, CDC2-active, cyclin protease
    dC = vi - vd*X*C/(0.02+C) - kd*C
    V1 = C/(0.5+C) * 3
    dM = V1*(1-M)/(0.005+(1-M)) - 1.5*M/(0.005+M)
    dX = M*(1-X)/(0.005+(1-X)) - 0.5*X/(0.005+X)
    return [dC, dM, dX]

t = np.linspace(0,200,2000)
sol = odeint(cycle, [0.01,0.01,0.01], t)
